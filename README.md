# Z-SAGA: CHRONICLES（オリジナル試作版）

起動方法: このディレクトリで `python3 -m http.server 8000` を実行し、ブラウザで `http://localhost:8000/` を開く。

## ファイル構成
- `index.html` / `style.css` / `main.js`: ゲーム本体
- `background.js`: フィールド背景描画 `drawMap(ctx, frame)` を独立させたモジュール（タイルベースの高品質背景）
- `sprites.js`: キャラクター用スプライトエンジン（外部PNGスプライトシートの読込・アニメーション制御。Canvas矩形やCSSでの人物描画はしない）
- `assets/`: ロゴ、時環観測室、時環の種子などの画像アセット置き場
- `assets/sprites/`: 主人公5職・仲間3職・敵7種の完成スプライトシート。仕様は [SPRITE_ASSETS.md](SPRITE_ASSETS.md) を参照
- `assets/ui/`: 星図を観測する「アズライト時環」と、休眠・覚醒・展開の3段階で変化する「時環の種子」

## 更新版のビジュアル

- 主人公・仲間・敵を、頭が大きめの低等身、太い濃色輪郭、絞った職業色で統一したクラシックRPG風ドット絵へ差し替え
- 仕立て・染色・採寸・裁断を冒険職へ再構成し、敵も毛玉・ハンガー・ほつれ糸・コサージュ・ミシン・継ぎ布・衣装棚で統一
- 既存作品の人物・衣装・紋章は使わず、縫い目・釦・鋏・糸巻き・メジャーを使ったZ-SAGA独自デザイン
- 48pxでも顔・髪・武器が判別でき、歩行・走行・攻撃中も輪郭がつぶれない設計
- 召喚画面を、六角形の星空孔・交差する軌道・不規則な結晶片による独自の観測演出へ変更
- 時環の種子は「休眠状態で出現 → 軌道が覚醒 → 結晶花へ展開」の順で進行
- 召喚結果では、仲間の実スプライトを大きく表示。染色術師はピンク・紫、採寸弓師は黄・緑、裁断戦士は赤・橙で、服装と道具も別デザイン
- B / A / S / SS / SSSごとに、光量・結晶光・軌道・星粒・カットインを段階的に増加
- 「伝説の継承」通知はランダム定期表示を廃止。服を出品し、購入者評価を受信した時だけ一度表示
- ローカル試作では出品25秒後に評価受信を一度だけ模擬。実サービスでは `receiveClothingReview(review)` をサーバー受信時に呼び出す
